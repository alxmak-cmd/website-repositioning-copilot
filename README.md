# Website Repositioning Copilot

## Problem

Marketing teams struggle less with writing new messaging than understanding the impact of changing existing messaging across an existing website.

## Solution

Website Repositioning Copilot analyzes a public website against a current and target positioning statement to identify impacted messaging, estimate effort, and generate rewrite recommendations.

## Workflow

1. Enter website URL
2. Enter current positioning
3. Enter new positioning
4. Analyze impact

## Output

- Impact level
- Confidence score
- Effort estimate
- Affected messaging
- Suggested rewrites

## Technology Stack

- FastAPI
- React + Vite
- Claude
- Trafilatura

## Future Enhancements

- Multi-page website analysis
- Impact scoring by page
- Prioritized rewrite recommendations
- Exportable content update plan
