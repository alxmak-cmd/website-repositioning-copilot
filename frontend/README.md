Website Repositioning Copilot

Problem:

Marketing teams struggle less with writing new messaging than understanding the impact of changing existing messaging across a website.

Solution:

Analyze a public website against current and target positioning to identify impacted messaging, estimate effort, and generate rewrite recommendations.

Workflow:

1. Enter website URL

2. Enter current positioning

3. Enter new positioning

4. Analyze impact

Output:

- Impact level

- Confidence score

- Effort estimate

- Affected messaging

- Suggested rewrites

Stack:

- FastAPI

- React/Vite

- Claude

- Trafilatura
